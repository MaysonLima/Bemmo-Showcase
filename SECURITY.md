# Segurança

Este repositório contém somente materiais públicos de apresentação da Bemmo e não deve armazenar segredos, credenciais ou dados reais de usuários.

O código-fonte principal permanece privado. Caso seja identificado algum problema envolvendo informação potencialmente sensível, evite publicá-lo em uma issue pública e utilize um canal privado de contato do responsável pelo projeto.
