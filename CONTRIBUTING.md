# Contribuição

Este é um repositório público de apresentação da Bemmo. O código-fonte principal é mantido em um repositório privado.

Sugestões sobre produto, documentação, UX e arquitetura são bem-vindas e podem ser abertas por meio de issues.

Pull requests com código da aplicação principal não fazem parte do objetivo deste repositório, já que ele funciona como vitrine técnica e documentação pública do projeto.

Não envie credenciais, dados pessoais, chaves de API ou outros segredos em issues, commits ou exemplos públicos.
